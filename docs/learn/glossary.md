# 用語集

| 用語 | 意味 |
|---|---|
| **DXF** | CAD の交換形式(線・円・レイヤー・単位)。`ezdxf` で読む |
| **POLYFACE MESH** | DXF の中の、3D メッシュのエンティティ(ルート B) |
| **平面図** | 建築の図面(壁・建具・家具・階段のレイヤー)。ルート C |
| **ルート A / B / C** | 2D 図面 + 推論 / 3D メッシュを直接 / 平面図の押し出し |
| **押し出し(extrude)** | 2D の線を高さ方向に立ち上げて 3D にする |
| **端点のスナップ** | 近い端点を同じ座標にそろえる(KD 木 + Union-Find) |
| **KD 木** | 空間の近傍探索のためのデータ構造 |
| **Union-Find** | 素集合データ構造。「同じグループ」を効率よくまとめる |
| **開口** | 壁に開けるドア・窓の穴 |
| **スラブ** | 床・天井の板 |
| **陸屋根 / 片流れ / 切妻 / 寄棟** | 平らな屋根 / 一方へ傾く / 二面の山形 / 四面 |
| **LOD** | 距離に応じた簡略モデル(LOD0 が最も細かい) |
| **Z バッファ** | 各ピクセルの最小の深さを持つ深度マップ。隠線判定に使う |
| **重心座標** | 三角形の内部の点を 3 つの重みで表す(内側判定・深さの補間) |
| **隠線** | 手前の面に隠れた辺(三面図では破線) |
| **シルエット** | 投影した外形 |
| **numba(`njit`)** | Python の数値ループを機械語にコンパイルする。初回は遅い |
| **Zero123++** | 1 枚の画像から、複数の視点の画像を作る拡散モデル |
| **TSDF Fusion** | 複数の深度・視点から、符号つき距離場でメッシュを作る |
| **TripoSR** | 1 枚から、メッシュを直接出すモデル |
| **シングルトン** | 同じ設定なら、同じインスタンスを使い回す(モデルの読み込みを 1 回に) |
| **CP932** | Shift_JIS の拡張。日本の CAD の DXF の文字コード |
| **ジョブ(API)** | `POST /convert` が登録する変換。状態は queued / running / done / failed |
| **TTL** | 保持の期限。過ぎた完了済みジョブを削除する |
| **202 Accepted** | 「受け付けた。処理は、あとで」というステータス |
| **error_category** | `input_error` / `inference_error` / `timeout` / `system_error` |
