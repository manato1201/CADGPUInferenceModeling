# CADGPUInferenceModeling 講義(基礎から)

CAD 図面(DXF)と 3D アセットを行き来するパイプラインの**核のアルゴリズム**を、順に学ぶ講義です。各回は「**ゴール → 説明と実行できる例 → 確認問題 → 解答 → まとめ**」で、コードは実際に動かして確かめてあります(`tests/test_docs.py` が、ずれと出力を検査します)。

| 回 | 題 | 学ぶこと | 目安 |
|---|---|---|---|
| [0](00-introduction.md) | 全体の見取り図 | 双方向の変換・3 つの核 | 1 h |
| [1](01-snap-endpoints.md) | 端点のスナップ | **KD 木 + Union-Find**・O(N log N)・許容距離・重心 | 2.5 h |
| [2](02-zbuffer.md) | Z バッファ | **重心座標**・深度の補間・隠線・`numba.njit` | 3 h |
| [3](03-encoding-and-capstone.md) | 文字コードと分類 | **CP932 と cp1252 の化け**・パターンを化けさせる・ルールの順序 | 3 h |

例は、リポジトリのルートで、`.venv` の Python で動かします(GPU・ネットワークは使いません)。講義のあとは [学習資料](../learn/index.md)。
