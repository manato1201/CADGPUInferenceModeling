## この回のゴール

- 日本の CAD 図面の**レイヤー名が文字化けして読める**理由(**CP932 を cp1252 として読んだ**もの)を説明できる。
- 「名前を直す」のでなく、「**照合するパターンを、化けた形に変える**」方針の理由を説明できる。
- 分類ルールの**順序**が結果を左右することを、動かして確かめられる。

## 1. 文字化けの仕組み

日本の建築 CAD の DXF は、**CP932(Shift_JIS の拡張)**で書かれていることが多い。ところが、ezdxf が読むとき、**1 バイトずつ cp1252(西欧の文字コード)として**解釈するため、レイヤー名「壁」(CP932 で 2 バイト `0x95 0xC7`)が、**2 文字の別の文字**(`•Ç`)になります。

名前を**元に戻す**のは、環境・ファイルで、うまくいったり、いかなかったりします(`_decode_layer` は、2 通りを試し、**失敗したら、そのまま返す**)。

そこで、このコードは**逆**をします。**探したい日本語(「壁」「建具」「階段」…)のほうを、同じ化け方にして**(`_cp932_moj`)、**化けた名前の中に含まれるか**を調べます(`_raw_match`)。

```python
# 実行できる
from core.floor_plan_extruder import _WALL_MOJ, _cp932_moj, _decode_layer, _raw_match

moji = _cp932_moj("壁")
print("「壁」を、ezdxf と同じ化け方にした文字列:", repr(moji), "(", len(moji), "文字 )")
print("日本語のままで探す(失敗する):", "壁" in moji)
print("化けた形で探す(成功する)  :", _raw_match(_cp932_moj("A-壁-外"), _WALL_MOJ))
print("名前を元に戻そうとしても     :", repr(_decode_layer(moji)), "(戻らないことがある)")
print("英語のレイヤー名             :", _raw_match("WALL_1", _WALL_MOJ), "(英語は、別の判定で拾う)")
```

```text
# 出力
「壁」を、ezdxf と同じ化け方にした文字列: '•Ç' ( 2 文字 )
日本語のままで探す(失敗する): False
化けた形で探す(成功する)  : True
名前を元に戻そうとしても     : '•Ç' (戻らないことがある)
英語のレイヤー名             : False (英語は、別の判定で拾う)
```

**ポイント**: 「**入力(名前)を直す**」より、「**照合する側を、入力に合わせる**」ほうが、**壊れにくい**ことがある。名前の復元は、環境に依存して失敗するが、同じ化け方を、パターン側に**決定的に**作れば、確実に一致する。

## 2. 分類ルールの順序

`_classify_layers` は、レイヤー名を**上から順に**照合し、**最初に当たったもの**で分類します。

| 順 | カテゴリ | 例 |
|---|---|---|
| 1 | 壁(wall) | `wall`・「壁」 |
| 2 | 開口(opening) | `door`・`window`・「建具」「ドア」「窓」 |
| 3 | 家具(furniture) | 「家具」「設備」 |
| 4 | 階段(stair) | `stair`・「階段」 |
| 5 | 無視(ignore) | `dim`・`text`・「寸法」「文字」「注記」… |
| 6 | その他 | 上のどれでもない |

**順序の落とし穴**: 「壁寸法」(壁の**寸法線**)は、**1 番目の「壁」に先に当たる**ので、**壁**として扱われ、「寸法」(無視)には**到達しません**。

```python
# 実行できる
from core.floor_plan_extruder import _classify_layers


class FakeLayer:
    def __init__(self, name):
        self.dxf = type("D", (), {"name": name})()


from core.floor_plan_extruder import _cp932_moj

names = ["WALL_1", _cp932_moj("壁"), _cp932_moj("建具"), _cp932_moj("寸法"), _cp932_moj("壁寸法"), "A-DIM", "misc"]
cats = _classify_layers(type("Doc", (), {"layers": [FakeLayer(n) for n in names]})())
labels = ["WALL_1", "壁", "建具", "寸法", "壁寸法", "A-DIM", "misc"]
for label, name in zip(labels, names):
    print(f"{label:8} → {cats[name]}")
```

```text
# 出力
WALL_1   → wall
壁        → wall
建具       → opening
寸法       → ignore
壁寸法      → wall
A-DIM    → ignore
misc     → other
```

「壁寸法」が **wall** になっているのが、順序の影響です(寸法線を壁として押し出してしまう可能性)。**直す案**: 「無視」(寸法・文字・注記)の判定を、**壁より前**に置く。ただし「無視」を先にすると、「壁(注記つき)」のような名前が無視される。**どちらが安全か**は、**実際の図面の命名**で決める(テストに、実データの例を入れる)。

## 3. 総合演習: 分類ルールに「ゾーン(zone)」を足す

**課題**: レイヤー名に「ゾーン」を含むものを、`zone` に分類し、**押し出しの対象にしない**ようにする。

1. `_ZONE_MOJ = [_cp932_moj(k) for k in ["ゾーン"]]` を足す。
2. `_classify_layers` の**どこに**判定を置くか決める(無視の**前**か、**後**か。順序の議論)。
3. `_collect_segments` 側で、`zone` を対象から外す。
4. テスト: 化けた名前・英語名・順序の取り合い。

```python
# 実行できる
from core.floor_plan_extruder import _cp932_moj, _raw_match

ZONE_MOJ = [_cp932_moj("ゾーン")]


def classify(raw: str) -> str:
    """演習: zone を最優先にした分類(まだ、本物の _classify_layers には入れない)。"""
    if _raw_match(raw, ZONE_MOJ) or "zone" in raw.lower():
        return "zone"
    return "other"


for label, name in [("ゾーン", _cp932_moj("ゾーン")), ("ゾーン境界", _cp932_moj("ゾーン境界")), ("ZONE-A", "ZONE-A"), ("壁", _cp932_moj("壁"))]:
    print(f"{label:6} → {classify(name)}")
```

```text
# 出力
ゾーン    → zone
ゾーン境界  → zone
ZONE-A → zone
壁      → other
```

### 自分で拡張する課題

1. 「壁寸法」を **ignore** にするには、どこを直す?直したとき、「壁(外壁)」は壊れないか、テストで確かめる。
2. `_snap_endpoints` の最小の長さ `cfg_min_snap`(50 mm)は、**モジュールの定数**で、引数で変えられない。引数にして、`ExtrusionConfig` から渡すには、どう直す?

## 確認問題

1. 「壁」を、文字化けした名前から探すのに、名前でなくパターンを変えるのは、なぜですか。
2. 分類ルールの順序で、「壁寸法」が壁になるのは、なぜですか。
3. 英語のレイヤー名(`WALL_1`)を、`_raw_match` で拾えないのは、なぜですか。

## 解答

1. 名前の復元は、環境・ファイルで**失敗することがある**。パターンを、同じ化け方に**決定的に変換**すれば、必ず一致する。
2. 上から順に判定し、**最初に当たったもの**で決めるので、「壁」(1 番目)に先に当たり、「寸法」(5 番目)に届かない。
3. `_WALL_MOJ` は、**日本語の「壁」を化けさせた**パターンだけ。英語は、別の判定(`"wall" in d`)で拾う。

## まとめ

- 日本語のレイヤー名は、**CP932 を cp1252 で読んだ化け方**で来る。**パターンを化けさせて**照合する。
- 分類は**上から順・最初の一致**。順序が結果を決める(「壁寸法」は壁になる)。
